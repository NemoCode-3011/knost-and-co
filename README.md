# Knost & Co.

A company website for Knost & Co., presenting the business through a branded web experience.

**Live website:** https://knost-and-co.vercel.app/

## Built with

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- React Router
- Motion
- React Hook Form

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

## Available scripts

```bash
npm run build
npm run lint
npm run preview
```

## Project scope

This repository contains the website frontend. Any enquiry or form workflow should be understood according to the current implementation; this README does not imply a separate backend or CRM integration.
